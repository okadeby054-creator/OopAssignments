# Library management system and fee management system

## Description

this are simple c++ projects , library managements system is build to enable students borrow books from the library and mark the books remaining in the library

while fees management system allows students to pay fees online and return the fee balaces and their details

### 1. Compile the Program

### library management system

```bash
g++ book.cpp -o book && ./book

```

### fees management system

```bash
g++ fee.cpp -o fee && ./book

```
